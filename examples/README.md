# Examples

This directory contains example skills that demonstrate contribution workflows and best practices for this repository.

## Sample Skills

### sample-skill
A complete example showing the proper structure and format of a skill. Use this as a reference when creating your own skills.

## Purpose

These examples serve to:
- Show proper skill structure and formatting
- Demonstrate best practices
- Provide templates for common patterns
- Help new contributors understand the workflow

## Using These Examples

1. **Study the structure**: Look at how skills are organized
2. **Copy the pattern**: Use similar structures for your skills
3. **Adapt to your needs**: Modify the examples for your specific use case
4. **Follow the guides**: Refer to [CONTRIBUTING.md](../CONTRIBUTING.md) for detailed instructions

## Creating Your Own Skill

Instead of modifying these examples, create your skills in the `skills/` directory:

```bash
# Copy the basic template
cp template/SKILL.md skills/my-skill-name/SKILL.md

# Or copy an example as a starting point
cp -r examples/sample-skill skills/my-skill-name
```
