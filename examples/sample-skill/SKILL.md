# Sample Contribution Skill

This is a demonstration skill that shows the basic structure and format of a skill in this repository. Use this as a reference when creating your own skills.

## Purpose

This skill serves as a working example of:
- Proper YAML frontmatter format
- Clear skill structure
- Documentation best practices
- How to organize skill content

## When to Use This Skill

This is a template/example skill. Real skills should:
- Solve a specific, well-defined problem
- Have clear instructions that Claude can follow
- Include practical examples
- Demonstrate best practices

## Instructions

When creating a new skill, follow these guidelines:

1. **Create proper frontmatter**
   - Use lowercase name with hyphens
   - Write a clear, complete description
   - Include any optional metadata if needed

2. **Write clear instructions**
   - Be specific and actionable
   - Use numbered lists for sequential steps
   - Use bullet points for related items
   - Break down complex tasks

3. **Provide examples**
   - Show typical use cases
   - Include expected outputs
   - Demonstrate edge cases if relevant

4. **Document edge cases**
   - Note any limitations
   - Explain error handling
   - Clarify assumptions

## Examples

### Example 1: Basic Task
```
User asks: "Can you help me with X?"
Claude uses skill to accomplish X following the instructions.
```

### Example 2: Complex Task
```
User asks: "I need to do Y which involves multiple steps"
Claude breaks down Y into steps and follows skill guidelines.
```

## Best Practices

- Keep instructions focused and specific
- Use clear, simple language
- Test your skill with various inputs
- Update documentation as needed
- Follow the repository's style guide

## Notes

- This is a demonstration skill
- Real skills should be more specific
- Always test your skills before submitting
- Review existing skills for inspiration
